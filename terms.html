Условия использования

AJOURE Mail — частная интеграция для владельца и разрешённых им почтовых аккаунтов. Использовать её можно только для ящиков и данных, которыми пользователь вправе управлять.

Каждое подключение требует согласия Google. Выбор аккаунта сам по себе не является поручением отправить письмо. Отправка и изменения писем выполняются по явным инструкциям пользователя с указанием соответствующего аккаунта.

Перед отправкой необходимо проверить отправителя, получателей, полный текст и вложения. При неопределённом результате отправки следует проверить состояние сообщения, прежде чем предпринимать дальнейшие действия. Копия в папке «Отправленные» подтверждает отправку со стороны Gmail, но не доставку получателю.

Доступ зависит от правил Google, настроек аккаунтов, доступности Gmail API и работы локальной среды. Пользователь может в любой момент отозвать доступ в настройках Google.

Почтовые данные обрабатываются в соответствии с политикой конфиденциальности. Контакт разработчика: 7500084@gmail.com.
