Политика конфиденциальности

Эта политика описывает частную интеграцию AJOURE Mail, разработанную Сергеем Федорчуком для работы с разрешёнными Google-аккаунтами на Mac mini.

Доступ и назначение

После отдельного согласия Google интеграция получает адрес аккаунта, данные писем и веток, метки и выбранные вложения. Доступ используется для поиска, чтения, подготовки и отправки сообщений, изменения меток и перемещения в корзину по поручениям пользователя. Разрешение gmail.modify не предоставляет постоянное удаление писем в обход корзины.

Хранение и обработка

OAuth-токены хранятся в Связке ключей macOS под именем приложения SergeyMail.GmailAPI. Конфигурация, сведения о подключениях и подготовленные письма сохраняются в локальной папке приложения с ограниченными правами доступа. Загруженные вложения и исходники писем сохраняются локально в выбранных файлах. Подготовки и загруженные файлы сохраняются до их удаления владельцем.

Запрошенное содержимое писем и вложений может передаваться в текущий чат Codex для выполнения поручения. Такая обработка выполняется поставщиком среды Codex в соответствии с настройками аккаунта пользователя и его политикой конфиденциальности. При отправке письма указанные пользователем текст и вложения передаются Google и выбранным получателям.

Ограничения использования

Приложение не продаёт почтовые данные, не использует их для рекламы, не создаёт рекламные профили и не использует их для разработки или обучения обобщённых моделей искусственного интеллекта. Для обработки почты следует использовать настройки и условия среды Codex, исключающие такое обучение на передаваемых данных.

Использование и передача информации, полученной через API Google, ограничиваются требованиями Google API Services User Data Policy, включая требования Limited Use.

Контроль и удаление

Пользователь может отозвать доступ в настройках подключений Google. Для удаления локальных данных нужно удалить записи приложения из Связки ключей и соответствующие файлы приложения, подготовки и загрузки на Mac mini. Удаление локальных данных не удаляет письма из Gmail и записи, уже сохранённые в истории чата. Историей чата управляют средствами Codex и аккаунта его поставщика.
